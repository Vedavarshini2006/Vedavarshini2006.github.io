# Vedavarshini B — Developer Portfolio

A responsive, dark black-and-purple student developer portfolio built with plain HTML, CSS and JavaScript. It is ready to publish using GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — responsive styling, dark theme and animations
- `script.js` — mobile navigation, current year and scroll reveal

## Run locally
1. Extract the ZIP file.
2. Open the `vedavarshini-portfolio` folder.
3. Double-click `index.html` to preview it in your browser.

No build tools or package installation are required. An internet connection is needed for the Google Fonts used in the design.

## Publish free with GitHub Pages
1. Sign in to GitHub: https://github.com/
2. Create a **new public repository** named exactly `Vedavarshini2006.github.io` (matching your GitHub username).
3. Upload `index.html`, `style.css`, `script.js` and this README to the repository's root. Do not upload the containing folder as an extra nested folder.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes and visit: https://vedavarshini2006.github.io/

If you already have a repository with that special name, upload these files to it instead. GitHub Pages may take a few minutes to publish after each update.

## Before sharing
- Check every project description and technology list for accuracy.
- Add project repository/demo links when you have public repositories. Do not invent links.
- Add certificate verification URLs and any additional completed certifications.
- Confirm that you want your phone number and email displayed publicly. Remove the phone link from `index.html` if you prefer email-only contact.
- Add a resume PDF and a download link if you want a resume button.
- Verify the displayed CGPA and all academic details against your latest resume.

## Updating
Edit `index.html` for text and links, `style.css` for appearance, and `script.js` for interactions. Commit and push changes to GitHub; Pages will redeploy automatically.
